FRONTEND 
- npm create vite@latest frontend -- --template react 
- User types → React stores values → Form submits → Backend receives data
- AccountForm - the form to create an account_type (sends POST req to backend)
- AccountCard - displays one account_type (sends GET /account/{id} req to backend)
- AccountList - holds all the cards (sends GET /account req to backend)

* AccountList = manager (owns all accounts)
* AccountCard = worker (shows one account)
* onEdit = “report back to manager”

bank-app/
├── backend/
│   ├── Dockerfile        ← recipe for your FastAPI app
├── docker-compose.yml    ← orchestrates FastAPI + PostgreSQL together
└── .env                  ← secret config values (DB password, secret key)

Instruction     What it does                                  Example 
FROM        Start from a base image                         FROM python:3.11
WORKDIR     Set the working directory inside the container  WORKDIR /app
COPY        Copy files from your machine into the container  COPY . .
RUN         Execute a shell command at build time           RUN pip install ...
CMD         The command that runs when the container starts CMD ["uvicorn", ...]

docker-compose.yml defines: allows both FastAPI & PostgreSQL to talk to eachother
├── service: db        ← a PostgreSQL container
└── service: backend   ← your FastAPI container

build — point it to the backend/ folder where your Dockerfile lives
ports — map your machine's port 8000 to the container's port 8000: "8000:8000"
depends_on — tell it to wait for db to start before starting FastAPI
env_file — point it to your .env file for secrets

Also add a volume so your data persists even if the container restarts. Without this, every restart wipes the database:
volumes:
  - postgres_data:/var/lib/postgresql/data


At the bottom of docker-compose.yml, declare the named volume you referenced in the db service:
volumes:
  postgres_data:
This tells Docker to create and manage a persistent storage volume.
